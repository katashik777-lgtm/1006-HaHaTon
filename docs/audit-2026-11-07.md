## Соответствие требованиям и оставшиеся ограничения

Основной контур модулей 3–4 работает и проверен: хранение, импорт, нормализация, сравнение,
фоновые задания, сводная, детализация, Python-проверки, роли, экспорт и резервирование.
Расхождения учебных примеров описаны в source-discrepancies.md; таблица всех разделов — requirements-matrix.md.

Расширенное ТЗ требует дополнительной разработки:

- Конструктор всех видов процедур приведения/сравнения/фактов и редактор зависимостей; сейчас пользовательский Python подключается как проверки, основной pipeline фиксирован.
- SQL/HTTP-адаптеры и реальное обогащение дополнительными источниками; сейчас есть файловый импорт и каталог, а не действующие внешние подключения.
- Визуальный мастер профиля с preview; сейчас профиль редактируется JSON.
- Полный экран скоркарт с версиями, распределениями, векторами и пересечениями порогов; текущий интерфейс покрывает часть требований.
- Фактическое сравнение двух отдельных прогонов в сценариях; текущий what-if — ограниченный продуктовый порог по AFTER.
- Подсветка точных диапазонов изменений в исходном JSON/XML; сейчас есть таблица сравнения и форматированный исходный текст.
- Полные связи проверок с заявками за пределами ограниченного APP_IDS. Выборка явно помечается ограниченной.
- Request ID для всех аудируемых событий; часть событий пока записывается без него.
- Полный многопользовательский нагрузочный тест, RSS, контролируемый холодный кеш и p95 pipeline; имеющиеся проверки конкуренции не заменяют нагрузочный тест.
- Проверка PostgreSQL, Linux-изоляции, реальных Windows/Linux-сборок и согласованного серверного восстановления; нужны целевые среды.
- Серверная установка и HTTPS; подготовленные systemd/Caddy-файлы не подтверждают развёртывание.

Mac Seatbelt не является лимитом памяти: RLIMIT_DATA на Darwin не применяется.
Локальный launch.py намеренно включает доверенный Python с правами пользователя; такой режим
нельзя считать изоляцией для чужого кода. Для изоляции на Mac используйте прямой запуск spr.cli
без SPR_TRUSTED_LOCAL_CODE. Windows поддерживает доверенное выполнение; изолированное отключено.
Прямой перенос каталога var между ОС не поддерживается — используйте backup/restore.

Проверка каталога и тесты не являются математической гарантией отсутствия всех ошибок.
