# Демонстрация на 20 минут

Для показа готового отчёта откройте [Скорифай](https://scorify-production.up.railway.app) и нажмите **Открыть готовый демоотчёт**. Для показа импорта, нового сравнения и редактора Python войдите с аккаунтом ведущего аналитика или администратора. Локальный запуск описан в [README](../README.md#локально-на-чистом-компьютере).

1. 0–3 минуты: датасет, общий профиль и сохранённая последовательность; новый прогон.
2. 3–6: журнал, этапы и зафиксированный снимок кода/параметров.
3. 6–7: обзор — 2002 валидные пары, 502 изменившиеся заявки, 385 смен решений на открытом наборе.
4. 7–10: сводная, уровни группировки, фильтры, различие количества заявок и суммы фактов.
5. 10–13: число → заявки → атрибуты → исходный ответ; возврат к сводной.
6. 13–15: качество и отдельный HTML-отчёт проверок. Откройте ссылку из HTML и покажите заявки, возвращённые проверкой.
7. 15–17: создайте проверку в редакторе и запустите её на открытом сравнении. Выполните две ячейки, чтобы показать сохранение переменных.
8. 17–18: скачать Excel и HTML, открыть детали изменений и перейти обратно по ссылке из HTML.
9. 18–20: архитектура, реальные замеры, восстановление и оставшиеся ограничения.
