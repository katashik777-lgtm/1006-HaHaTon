# Оставшаяся работа

Полное исходное ТЗ пока не выполнено. Этот список отделяет работающий локальный контур от дальнейших задач.

- Нет проверенного развёртывания на удалённом сервере: отсутствуют SSH-реквизиты и домен для HTTPS. Шаблоны systemd/Caddy подготовлены, но их работа не проверена на Linux.
- Windows не исполняет произвольные Python-процедуры. Linux/macOS-исполнитель требует проверки изоляции на целевом хосте. Четыре соответствующих теста на Windows пропускаются.
- Конструктор поддерживает параметры, код, порядок и сохранение проверок. Пользовательские процедуры приведения/сравнения/фактов и редактор графа зависимостей ещё не реализованы.
- SQL- и HTTP-адаптеры дополнительных источников отсутствуют; каталог содержит описание файловых источников. Доступ к ФНС/МВД не настроен.
- PostgreSQL поддержан SQLAlchemy и миграцией, но конкурентный доступ, установка и резервное восстановление на PostgreSQL не проверены.
- Профили редактируются как JSON; отдельного визуального мастера сопоставления и preview импорта нет. CSV содержит одну заявку на файл.
- Нативные ответы показываются форматированным текстом; адреса и изменившиеся значения видны в таблице. Подсветка точных диапазонов нативного JSON/XML не реализована.
- Скоркарты показывают группы/предикторы, API рассчитывает распределения; полный интерфейс распределений, целевых моделей и пересечения порога требует доработки.
- What-if упрощён до одного продуктового порога, балла и стоп-факторов AFTER; банковскую стратегию целиком не воспроизводит.
- Полные списки для ограниченных APP_IDS пользовательских проверок не восстанавливаются автоматически; показанная выборка ограничена самим результатом проверки.
- Performance-измерения не включают пик памяти, холодный дисковый кеш, p95 полного pipeline и нагрузку нескольких браузерных пользователей. Цель 30 секунд нельзя считать подтверждённой.
- Публикация Windows использует атомарное переименование и fsync файлов; fsync каталога доступен только на POSIX. Согласованная резервная копия требует остановки API и worker.
