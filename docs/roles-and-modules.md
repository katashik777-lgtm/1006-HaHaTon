# Роли и дополнительные модули

| Роль | Возможности |
|---|---|
| Администратор | Все проекты, пользователи, назначение/отзыв ролей, управление администраторами |
| Ведущий аналитик | Свои проекты: профили, Python, последовательности, пулы и исполнение, история; вся аналитика |
| Аналитик | Чтение, импорт, запуск утверждённых процедур, сценарии, заметки и экспорт; без изменения профилей/кода |
| Наблюдатель | Чтение и экспорт разрешённых проектов |
| Зарегистрированный без роли | Вход и ожидание назначения доступа |

Права проверяются API. Администратор не может снять собственный административный доступ. Удаление проектной роли отзывает доступ, смена прав завершает сеансы другого пользователя. Пароли и токены не возвращаются в списках пользователей.

## Модули 1–2

В меню ведущего аналитика и администратора «Модули 1–2» можно загрузить JSON-массив заявок, проверить уникальные id и отобрать пул точными фильтрами. Пул сохраняется отдельно от ответов.

Демонстрационный режим: строки `{ "id":"1", "score":0.3, "stops":[false,null], "product":"demo" }`. Для каждой версии задаются порог и направление. true в stops даёт отказ независимо от балла; null или отсутствующий скор — UNKNOWN. Это модель одного правила, не банковская стратегия. Полученный датасет выбирается в конструкторе с профилем main.

HTTP-режим требует переменных сервера SPR_BEFORE_URL, SPR_AFTER_URL и необязательных SPR_BEFORE_TOKEN, SPR_AFTER_TOKEN. POST передаёт `{application: <исходная заявка>, version: <настройки версии>}`. Ответ — JSON СПР с appData.application_id, равным id заявки, и decisionResult. Redirect не выполняется. Секреты хранятся в окружении, не в проектных объектах. Ограничение: 100 заявок, 15 секунд на запрос; автоматического повтора нет. При ошибке датасет не публикуется. Для реального банковского контракта понадобится согласовать адаптер; подключение не проверено.

На экране «Скоркарты» доступна совместная проверка порога и стоп-факторов с выбором направления и переходом в заявку. Старые артефакты без STOP_UNKNOWN считаются неопределёнными, а не автоматически пройденными. Для полного результата пересчитайте датасет. Ограничение интерфейса — первые 500 продуктовых строк, это явно указано.
