## Автотесты и сборка

`python -m pytest -q`: **27 passed, 4 skipped**. Пропущены проверки изолированного пользовательского Python: Linux/macOS-изоляция на текущем Windows недоступна. Предупреждение Starlette о будущем переходе TestClient с httpx на httpx2 не влияет на результат. `pip check`: конфликтов зависимостей нет.

Проверены учебные профили 12/14/26/14 и шесть изменений, режимы массивов и коллизии, типы/отсутствие, бакеты, технические исключения, JSON/XML/CSV, отказ от XML external entities, неполные пары, distinct counts и соответствие drill-down, контрольные суммы. Новые интеграционные тесты проходят настоящий API, импорт, worker, четырёх конкурирующих претендентов на одно задание, отмену/повтор, восстановление после публикации до SQL-коммита, observer/outsider и прямые ссылки, HTML/CSV/JSON, отфильтрованный экспорт и резервное восстановление с переносом путей.

Фронтенд: TypeScript `--noEmit` и Vite production build проходят. Сохраняется предупреждение о JS-бандле свыше 500 КБ; разделение на чанки не выполнено.

Браузерная проверка Playwright/Edge: вход → конструктор → запуск → завершение → KPI → заявка → исходный JSON → сводная → её заявки → перезагрузка прямой ссылки. Проверен готовый интерфейс визуально. JavaScript page errors: 0. Тест не заменяет отдельные проверки всех экранов и ролей.

## Данные и производительность

| Набор и условия | Пары | Нормализованные строки | Полный pipeline | Сводная median / p95 | Drill-down median / p95 |
|---|---:|---:|---:|---:|---:|
| Открытый, первый замер | 2 002 | 572 221 | 62,93 с | 61,7 / 76,7 мс | 10,8 / 11,9 мс |
| Открытый, повторное чтение, 1 поток I/O | 2 002 | 572 221 | 5,50 с | 52,5 / 61,9 мс | 8,5 / 10,7 мс |
| Открытый, повторное чтение, 4 потока I/O | 2 002 | 572 221 | 6,29 с | 52,5 / 59,3 мс | 8,9 / 9,9 мс |
| Синтетический, 40 000 файлов | 20 000 | 281 819 | 374,28 с | 58,6 / 68,5 мс | 9,4 / 12,2 мс |

В открытом наборе 502 изменившиеся заявки, 385 смен решений, 14 412 изменений атрибутов. В синтетике 11 688 изменившихся заявок, 2 858 смен решений, 15 344 изменения. Синтетические документы проще настоящих; это проверка количества ID, а не эквивалентный стресс-тест 20 тысяч банковских ответов.

Для каждого запроса выполнено 20 повторов; p95 — 19-е значение отсортированного ряда из 20. Каждый pipeline измерен один раз. Генерация синтетики не входит в время pipeline. Кеш ОС не очищался, поэтому первый замер не называем контролируемым холодным запуском, а разницу 62,93 → 5,50 с не приписываем изменению алгоритма. Первичное чтение мелких файлов — основная наблюдаемая задержка. По повторным измерениям последовательное чтение быстрее четырёх потоков, поэтому оно оставлено основным; ограниченный prefetch доступен для сравнений через `--read-workers`.

Отдельный эксперимент чтения/парсинга/нормализации и хеширования: последовательно 4,11 с, ProcessPoolExecutor с четырьмя spawn-процессами и пакетами по 32 файла — 1,92 с. Хеши и количество всех 572 221 строк совпали. Эксперимент возвращает только хеши/числа: IPC строк и публикация Parquet не входят в замер. Поэтому перенос пула в основной pipeline пока не обоснован полным измерением.

Сырые результаты сохранены в `docs/performance/*.json`, команды — в README. Цели интерактивных запросов выполнены в этих локальных замерах. Гарантии ≤30 секунд на первом запуске, пиковое потребление памяти, p95 полного pipeline, отдельные времена HTTP/рендеринга и несколько одновременных браузерных пользователей **не подтверждены**.

## Сервер и незакрытые требования

Пакет systemd/Caddy и руководство подготовлены, но SSH-доступ/HTTPS, PostgreSQL, Linux-изоляция и серверные нагрузочные тесты не выполнены. Полный список функциональных пробелов находится в `limitations.md`, статусы каждого раздела — в `requirements-matrix.md`.
